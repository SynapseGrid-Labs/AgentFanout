# Presentation assets

The README uses two locally rendered PNG illustrations:

- `readme/agentfanout-overview.png` — your main chat coordinates focused agents
  and receives concise findings; agent/model choice depends on the app.
- `readme/agentfanout-waves.png` — searches, notes and intermediate work stay in
  agent conversations while your main chat reviews the useful findings.

Both retain the AF brain/chip emblem from the repository's original
`agentfanout-orchestrator.jpg` illustration. Only emblem pixels are reused;
wording, diagrams and line icons are newly drawn on CPU. The established
blue/purple palette and gradient wordmark are retained. The emblem comes from
existing public MIT repository asset history; its original creation method
is not recorded. No third-party provider logos or competitor artwork are included.

These repository assets are covered by the MIT license. Nimbus Sans is rasterized
into the images; no font software is distributed. PNGs contain no EXIF, XMP,
comments, embedded thumbnails, scripts or external resources. The illustrations
are conceptual, with no screenshots or real account data.

The diagrams explain intended context management and delegation. They are not
performance graphs or measured token/cost comparisons. Model choice is conditional
on app support, agents also consume usage, and context compression can still occur.
Existing public history is unchanged. Adding these files does not change any
social-preview setting or authorize publication.
