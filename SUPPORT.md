# Support

Use GitHub Issues for:

- usage questions
- documentation gaps
- routing or sanitizer bugs
- provider adapter suggestions
- examples that should be added to the README or references

For public contact paths across SynapseGrid Labs projects, see <https://synapsegridlabs.com/contact/>.

For security-sensitive issues, follow [SECURITY.md](SECURITY.md). Do not post secrets, credentials, private infrastructure details, or harmful exploit payloads in public issues.

AgentFanout is currently a `v0.1.1` skill and advisory router. It does not ship a standalone worker dispatcher.
