# Feature and profile status

The selected [release assessment](release-scope.md) covers the lightweight native
skill and the reviewed Codex native integration. Standalone strict-runtime and
Grok/provider profiles remain preserved outside this release's accepted scope.
This selection is not final human acceptance or publication authorization.

The source retains version `0.4.0-rc.1`. The proposed source tree still contains
the complete repository: skill, optional integrations, schemas/tests, disabled
upgrade contracts and isolated experiments. A Git branch upload includes all
those files; acceptance scope is not a packaging exclusion or a leakage waiver.

## Evidence categories

| Category | What this candidate contains or requires |
| --- | --- |
| Implemented, covered by offline fixtures | Native wave planning, compact packets, Codex hook state/decision guards, legacy hosted helpers, host authorization/ledger/recovery, exact Local/profile/egress contracts, fresh ACP worker/validator primitives, reference wire/usage mapping, mixed transitions and diagnostic isolation. |
| Historical partial live observation | Credential-free installed Grok initialization and plugin manifest validation only. Neither establishes authenticated session controls, no-tool inference, billing or usage semantics. These are historical observations, not tests of this revision. |
| Disabled candidate behavior | `GrokCLI` subscription, coordinator-backed Local, mixed hosted runs and native Grok profile controls. No production transport, coordinator deployment or live capability is inferred from fixtures. |
| Missing conditional implementation | A separately bound installed Grok post-auth/notification/usage codec if observed supported shapes differ from the reference. A rejected diagnostic is not admitted by renaming it. |
| Deferred implementation | Retained subscription sessions, tool-capable upgrade workers, generalized provider-neutral native V2 and broader framework adoption. |
| Live prerequisites | Official auth preference/API-fallback refusal, installed model/effort/tool/bootstrap/usage/cancellation proof, enforceable spending policy; exact Local artifact/backend/profile/epoch and role/resource conformance; separately authorized mixed runs. |
| Human prerequisites | Profile-specific UAT, exact README/image approval and separate authorization for any public branch upload or PR. No approval is supplied by this document. |

AEON contracts preserve the selected BF16 artifact without substitution.
Nemotron precision, backend and served identity require their own evidence;
names or metadata do not establish hardware execution support. The coordinator
owns lifecycle, fencing, reservations and inference. Its deployment-specific
implementation is external to this repository. Credentials remain host-local.

Hosted and native/V2 contracts remain distinct. New state/guard schemas preserve
old meanings and immutable history; active runs are not migrated or downgraded.
Unknown cancellation, accounting or ownership retains the compatible runtime and
blocks replay/release. See [compatibility](mixed-contract-compatibility.md),
[GrokCLI](grok-subscription-contract.md), [Local](coordinator-local-contract.md),
and [public UAT](public-uat.md).

No measured economic or quality improvement, included allowance, current live
model availability, production adoption or universal anti-bypass is claimed.
