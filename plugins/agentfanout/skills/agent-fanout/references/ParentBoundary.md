# Parent boundary

The parent owns orchestration, structural packet/ledger validation, private
tools and data, credentials, git state, irreversible actions, external side
effects, and final synthesis after residual delegable work reaches zero.
Substantive correctness checks remain fresh-worker work when risk,
contradiction, or the user requires them. Delegable research, inspection,
implementation, debugging, and verification remain worker work.

Consume compact packets only. Preserve evidence and uncertainty; do not ingest
raw transcripts, route JSON, hidden prompts, or provider credentials.

Codex plugin hooks enforce mandatory stop continuation, a tokenized replan
declaration, and supported-tool denial between batches. They do not
independently prove the residual declaration. Codex documents incomplete
interception, so this is not universal anti-bypass enforcement. Other native
hosts remain advisory unless they prove an equivalent boundary.
