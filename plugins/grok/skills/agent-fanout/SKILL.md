# AgentFanout for Grok

Prefer native Grok agents for a useful task; keep ordinary prompts unchanged.
Use the portable AgentFanout wave and compact result contracts.
Keep secrets, private tools, git mutation, destructive actions, and synthesis in the parent.
Confirm actual native spawn/wait/cancel and receiver identities before launching.
Keep worker scope bounded and non-overlapping; collect evidence, uncertainty, and residual work.
Rebuild residual work after each batch; stop at configured limits or no progress.
Validation is optional for low-risk native work and required when risk or contradictions justify it.
Label native coordination advisory unless the host proves stronger enforcement.
Select `GrokCLI` only through the explicit hardened subscription profile.
Run `python3 scripts/grok-agentfanout.py --profile grok_cli_subscription_acp status` for its capability.
A rejected strict lane stays blocked; never substitute API Grok or advisory execution.
Present runner status accurately; passive Stop observation cannot constrain the parent's speech.
