# Parent boundary

The parent owns private tools, credentials, secrets, private data, git state,
destructive or irreversible actions, external side effects, orchestration,
structural packet/ledger validation, and final synthesis after residual
delegable work reaches zero. Substantive correctness validation belongs to a
fresh worker when risk, contradiction, or the user requires it.
Research, inspection, implementation, debugging, and verification remain worker
work whenever they are delegable. Workers receive bounded scopes and may not
expand their files, tools, network access, or authority.

The parent consumes compact packets only. Preserve evidence references and
uncertainty; do not include raw worker transcripts, route JSON, hidden prompts,
or provider credentials in parent context or user output.

Native skill mode is advisory unless the host reports a trusted enforcement
level. The Codex plugin lease enforces mandatory stop continuation, a tokenized
replan declaration, and supported-tool denial between batches. It does not
independently prove the residual declaration, and Codex documents hook
interception as incomplete; do not describe it as universal anti-bypass. Explicit
enforced-runtime requests remain fail-closed when unavailable.
